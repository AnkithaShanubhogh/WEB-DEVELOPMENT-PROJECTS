# JavaScript Promo Code Discount Project

## Project Description
Create a simple ticket booking promo code application
using HTML, CSS and JavaScript.

## Base Ticket Price
$50

## Valid Promo Code
HALF

## Discount
50% discount when the user enters HALF.

## Prompt 1: Fix TypeError
Understand why JavaScript gives:
TypeError: Cannot set properties of null
(setting 'textContent').

Check whether the HTML element exists and
whether JavaScript runs after HTML loads.

## Prompt 2: Fix Form Submission
Prevent the form from refreshing the page.
Use event.preventDefault().

## Prompt 3: Fix applyDiscount()
Use the comparison operator === instead of
the assignment operator =.

## Prompt 4: Modernize JavaScript
Use const and let instead of var.
Use clean functions and readable code.

## Prompt 5: Improve the Application
Make promo codes case-insensitive.
Accept HALF, half and Half.
Use trim() and toUpperCase().
Add proper validation and error messages.

## Expected Result
Original Price: $50
Valid Promo Code: HALF
Discount: 50%
Final Price: $25
