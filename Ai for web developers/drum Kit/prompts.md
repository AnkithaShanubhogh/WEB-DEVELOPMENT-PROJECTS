
# Interactive Drum Kit App

## Project Description
Build an interactive drum kit using HTML, CSS and JavaScript.

## Prompt 1: Create Drum Button
- Create a KICK button.
- Center the button on the screen.
- Play kick.wav when clicked.

## Prompt 2: Keyboard Interaction
- Trigger kick sound using the A key.
- Use the keydown event.

## Prompt 3: Code Optimization
- Use reusable JavaScript functions.
- Use const and modern JavaScript.
- Avoid repeated code.
- Use addEventListener().

## Prompt 4: Multiple Drum Sounds
Include all nine instructor-provided sounds:
1. boom.wav
2. clap.wav
3. hihat.wav
4. kick.wav
5. openhat.wav
6. ride.wav
7. snare.wav
8. tink.wav
9. tom.wav

## Prompt 5: Multiple Buttons and Keyboard
- Create nine drum buttons.
- Assign one keyboard key to each button.
- Play the matching sound.
- Add button animations.

## Technologies
- HTML
- CSS
- JavaScript

## Expected Result
Users can play all nine drum sounds
using mouse clicks or keyboard keys.
